# 澄清流程

[返回总入口](../../SKILL.md) · [信息决策门](./ambiguity-gate.md) · [选项题格式](./choice-question-format.md)

只在 [ambiguity-gate.md](./ambiguity-gate.md) 判定信息严重不足时使用。

## 目标

用最少问题减少会改变结论的不确定性，而不是收集所有可能相关的信息。

## 负载规则

- 首轮最多 `2` 题：通常先问目标，再问最近一次关键事件或最关键结构位。
- 中段通常只问 `1` 题；确有两个并列关键分叉时才问 `2` 题。
- 收口前最多补 `1` 个堵点。
- 如果现有信息已经能支持条件化判断，停止追问并进入分析。
- 用户要求先分析或不追问时，给有限结论并说明假设。

## 优先补什么

按影响结论的程度选择，不机械走完整清单：

1. 用户要推进的结果。
2. 最近一次最能说明问题的具体事件。
3. 关键人物/对象以及用户所处位置。
4. 决策、信息、资源或执行控制点。
5. 已做尝试及其结果。
6. 现实约束、底线和不能承受的代价。

## 每轮写法

1. 用 `1` 到 `3` 句复述已经确认的内容。
2. 说明现在最缺哪个会改变判断的信息。
3. 问最少的问题。
4. 简短说明答完后会进入什么判断。

保持 `摆清情况 / 点出主导缺口 / 提出当前问题` 三段功能和顺序；标题不要求逐字固定，也不重复固定口号或引导句。

## 什么时候收口

满足下面条件即可进入问题重述和分析：

- 目标基本清楚。
- 至少有一个具体事件或事实入口。
- 能辨认关键对象和主要约束。
- 剩余未知项可以通过条件、假设或验证动作处理。

不要求控制点、可团结对象、完整事件链等字段在所有题型中一律齐全。

## 紧急例外

命中安全、医疗、法律、财务或暴力胁迫风险时，转到 [safety-escalation.md](../risks/safety-escalation.md)。先止损，不发常规问卷。

## 禁止事项

- 不一边追问一边偷塞未经支持的强结论。
- 不把选项设计成诱导用户接受模型判断。
- 不连续多轮重复询问已经回答过的字段。
- 不因追求完整而拖延一个已经可以给出的有用初判。
